    <span>Sistemas de Banco de Dados para Biblioteca</span>
</h1>

Repositório desenvolvido para fins didáticos na prova prática de Sistemas Gerenciadores de Banco de Dados.

<h2>
    <span>📚 Descrição</span>
</h2>
Este projeto foi desenvolvido como parte da disciplina <b>Sistemas Gerenciadores de Banco de Dados</b>.<br>O objetivo é modelar e implementar um banco de dados para uma <b>biblioteca</b>, incluindo:<br>- Criação de <b>6 tabelas</b>.<br>- Inserção de dados usando INSERT INTO.</br>
- Consultas em SQL para obtenção de informações relevantes.  

<h2>
    <span>🗂️ Estrutura do Banco </span>
</h2>
As tabelas criadas representam os principais elementos de uma biblioteca: <br>- Authors</br> - Genres <br>- Customers</br> - Publishers <br> - Books</br> - Sales
<p>Cada tabela possui suas <b>chaves primárias</b> e <b>relacionamentos</b> definidos por <b>chaves estrangeiras</b>.</p>
